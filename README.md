# Your Mail Is Screaming

Dead-Letter House is a two-player Roblox mystery. One courier reads a witness statement, and the other matches the clue to a brass seal. The couriers swap roles as they work through three rooms.

## Play in Studio

Open [the Roblox place](First%20Delivery/Your%20Mail%20Is%20Screaming.rbxlx) in Studio. Start a **Server & Clients** test with two players and have both join the same numbered booth.
